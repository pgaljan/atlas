
# Dependencies

This project uses the following dependencies and devDependencies:

---

## Core Libraries
- **react** (^18.3.1): Frontend library for building user interfaces.
- **react-dom** (^18.3.1): Renders React components to the DOM.
- **prop-types** (^15.8.1): Runtime type checking for React props.

---

## Routing & State Management
- **react-router-dom** (^7.2.0): Client-side routing and navigation.
- **@reduxjs/toolkit** (^2.6.0): Modern Redux state management.
- **react-redux** (^9.2.0): React bindings for Redux.

---

## UI & Styling
- **tailwindcss** (^3.4.17): Utility-first CSS framework.
- **@tailwindcss/typography** (^0.5.16): Tailwind plugin for typography.
- **tailwind-merge** (^3.2.0): Utility for merging Tailwind class names.
- **clsx** (^2.1.1): Conditional className utility.
- **flowbite-react** (^0.10.2): React components built with Tailwind.
- **framer-motion** (^12.14.0): Animation and motion library for React.
- **react-icons** (^5.5.0): Popular icon library for React.
- **react-avatar** (^5.0.3): Avatar generation and display.
- **tippy.js** (^6.3.7): Tooltips for better UI.

---

## Editors & Visualization
- **@monaco-editor/react** (^4.7.0): Monaco code editor (used in VS Code).
- **react-quill** (^0.0.2): Rich text editor.
- **quill-image-resize-module-react** (^3.0.0): Image resize module for Quill.
- **highlight.js** (^11.11.1): Syntax highlighting for code.
- **react-syntax-highlighter** (^15.5.0): React wrapper for syntax highlighting.
- **markmap-toolbar** (^0.18.10): Toolbar for Markmap (mindmaps).
- **markmap-view** (^0.18.10): Visualization for mindmaps.
- **mermaid** (^11.9.0): Generate diagrams and flowcharts.
- **d3** (^7.9.0): Data visualization library.
- **plantuml-encoder** (^1.4.0): Encode UML diagrams.
- **katex** (^0.16.22): Math rendering.
- **hugerte** (^1.0.9): Hugerte integration library.

---

## Utilities
- **axios** (^1.8.1): Promise-based HTTP client for API calls.
- **crypto-js** (^4.2.0): Cryptography library for hashing and encryption.
- **date-fns** (^4.1.0): Utility library for date manipulation.
- **lodash.debounce** (^4.0.8): Debouncing utility function.
- **js-cookie** (^3.0.5): Cookie management in browser.
- **use-undo** (^1.1.1): Undo/redo hook for React.

---

## File & Document Handling
- **file-saver** (^2.0.5): Save files from the browser.
- **jszip** (^3.10.1): Create and read ZIP files.
- **jspdf** (^3.0.1): Generate PDF documents.
- **html-to-image** (^1.11.13): Convert HTML nodes to images.
- **dompurify** (^3.2.6): Sanitize HTML to prevent XSS attacks.
- **marked** (^15.0.12): Markdown parser.

---

## UI Enhancements
- **react-beautiful-dnd** (^13.1.1): Drag-and-drop support for React.
- **react-window** (^1.8.11): Windowing for rendering large lists.
- **react-select** (^5.10.1): Select component with advanced features.
- **react-date-picker** (^12.0.1): Date picker component.
- **react-datepicker** (^8.5.0): Another date picker with more options.
- **@successtar/cogo-toast** (^5.0.6): Toast notifications.
